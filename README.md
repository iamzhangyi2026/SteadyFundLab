# steady-fund-lab

> **虚拟资金 + 真实规则的基金交易沙盒**——用一套可追溯、可复盘的系统，从全市场 2.4 万只基金里找「估值洼地（历史分位低）+ 趋势向上」的标的。

一个本地运行的基金投研沙盒：**资金是虚拟的，规则是真实的**。它把「资讯抓取 → 事件提取 → 传导链映射 → 资金验证 → 筛选 → 纪律线 → 下单记账 → 复盘」整条链路做成一个自运转的系统，AI 负责执行，人负责总控。

---

## 解决什么问题

- **信息过载**：财经新闻每天上千条，人工看不过来 → 系统自动抓取、分类、提炼成可决策的信号
- **找不到洼地**：全市场 2.4 万只，不知道从哪看 → 用「历史分位 + 趋势 + 回撤」量化筛选
- **消息到持仓之间断链**：看到新闻不知道该看哪些行业、哪些基金 → 事件→行业/概念映射 + 资金流验证
- **纪律难执行**：盈利该止盈、回撤该减仓，都是事后才发现 → 纪律线自动巡检、提前提醒
- **规则记不住**：15:00 截单、T+1 确认、阶梯赎回费、FIFO 批次 → 全部由引擎算，不靠人记

## 核心能力

| 模块 | 做什么 |
|---|---|
| **筛选引擎** | 历史分位 < 50% + 近 1 年收益 > 0 + 最大回撤 < 50%；买入前额外要求回撤 < 30%。口径是**净值历史分位**，不是 PE/PB（基金没有 PE/PB） |
| **资讯三路** | RSS 13 个源 + 盘中快讯 3 个源 + 政府宏观 6 项指标，全部内建定时抓取，不依赖外部 cron |
| **事件提取** | 六类事件（政策/地缘/军事/会议/宏观/公司）+ 可信度四档；跨轮次多源交叉验证 |
| **传导链映射** | **两层**：① 事件类别规则（如「出口管制」→ 半导体/军工/信创）② 行业词反查；再用板块资金流验证「市场认不认」 |
| **信息时差** | 海外源=海外事件首发地、国内源=国内事件首发地 → 抢时差找洼地 |
| **交易引擎** | 外扣法申购费、阶梯赎回费（按**自然日**）、**FIFO 批次**（同基金分批买入费率不同，平均成本法会算错）、15:00 截单、T+1/T+2 确认、赎回到账日才可用 |
| **纪律线** | 止盈 +20% / 回撤 −15% / 认错 −5%，只跑不误，仅跑一次自检；定投时优先跑风控自检 |
| **持仓穿透** | 行业暴露、风格漂移检测、重叠度检测（≥3 只重仓重复 = 假分散） |
| **可靠性** | 后端黑匣子日志 + Electron 看护自愈 + 崩溃可见 + 诊断接口 |

## 最新更新

- **真实持仓区（B 区）**：独立于模拟盘的真实仓位管理——独立数据库与模拟盘物理隔离，持仓总览、收益 / 回撤指标、历史快照一页看清；AI 可读持仓并生成分析（只读参考，不代操作）
- **持仓截图导入**：券商持仓页截图 / 文本粘贴 → OCR 识别 → 人工确认后入库，免手动录入
- **持仓资讯**：按真实持仓自动抓取基金公告与前十大重仓股新闻，只增不删，公告与个股新闻分类展示
- **宏观六项**：GDP / CPI / PPI / 货币 / 信贷 / 外贸宏观指标定时抓取入库，与资讯统一消费
- **定投防护**：定投池只认「已启用的计划」，绝不回退到候选池，杜绝误买

## 快速开始

```bash
# 1. 便携运行时已自带依赖，无需 pip install
cd fund-sandbox

# 2. 准备配置（从配置模板复制）
cp config/config.toml.example config/config.toml

# 3. 初始化数据库
runtime/python/python.exe -m backend.db.schema

# 4. 启动后端
runtime/python/python.exe -m uvicorn backend.api.main:app --host 127.0.0.1 --port 8765

# 5. 访问
open http://127.0.0.1:8765          # API + 前端
open http://127.0.0.1:8765/docs     # 交互式 API 文档
```

桌面版：双击 `fund-sandbox/启动.bat`（Electron 自动拉起后端）。

## 数据与运行

运行所需的依赖、便携运行时与本地数据库不在仓库内，按上方「快速开始」步骤在本地准备；配置文件从 `config.toml.example` 复制创建。

服务只在本机运行；CORS 只放行本机来源。
